# barcode-gen

This is a simple barcode generator for sticker paper like this one:

- https://printation.de/etiketten/
- https://www.amazon.com/Address-Labels-Sticker-Printer-mailing/dp/B09P16YV2K/
- ...

Set up the margins etc correctly, set ASN prefix, and go :)

Works great with [paperless-ngx](https://docs.paperless-ngx.com/)
